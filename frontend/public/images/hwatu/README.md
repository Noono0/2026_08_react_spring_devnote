# 화투 그림 출처

이 폴더의 `Hwatu_*.svg` 40장(1~10월 × 4장)은 위키미디어 공용(Wikimedia Commons)에 올라온
**Mliu92**의 작품이며 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko) 라이선스를 따릅니다.

- 출처 분류: <https://commons.wikimedia.org/wiki/Category:SVG_Hwatu_(with_Japanese-style_artwork)>
- 파일 페이지: `https://commons.wikimedia.org/wiki/File:<파일 이름>` (예: `File:Hwatu_January_gwang.svg`)
- 원본 파일을 고치지 않고 그대로 씁니다. 고쳐서 쓰면 고친 파일도 CC BY-SA 4.0으로 공개해야 합니다.

섯다 화면(`frontend/src/features/games/online/games/sutdaRules.ts`)은 월마다 두 장(광·열끗 1장 + `pi_1`)만 씁니다.
나머지(띠 `tti`, 두 번째 피 `pi_2`)는 미리 보기와 앞으로의 화투 게임용으로 함께 보관합니다.
화면의 족보표 아래에도 작가·라이선스·출처 링크를 표시합니다.
